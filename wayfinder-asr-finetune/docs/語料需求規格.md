# 語料需求規格

本文件說明 Wayfinder 視障指令 ASR 微調所需的語料：要收什麼、怎麼錄、怎麼標、收多少、怎麼切分。

---

## 一、原則：ASR 語料重的是聲學與詞彙覆蓋

本專案微調的是**語音辨識**，不是對話模型。語料重點不在語意多樣，而在：

| 不重要 | 重要 |
|---|---|
| 同一個意思有多少種說法 | 同一句話有多少**不同的人**講過 |
| 對話輪次、上下文 | 專有詞彙（物品名、顏色、方位）有沒有被念到 |
| 回應內容 | **容易聽錯的詞有沒有成對出現** |

一句話被 10 個人各念 1 次，遠比 1 個人念 10 種說法有用。

### 最小對立組（優先級最高）

系統會依辨識結果提供路口導引，聽錯以下詞彙會造成安全風險，語料必須讓它們**成對、大量、跨噪音條件**出現：

| 對立組 | 風險 |
|---|---|
| 紅燈／綠燈 | 號誌判斷錯誤 |
| 左邊／右邊 | 方向錯誤 |
| 前面／後面 | 方向錯誤 |
| 可以／不可以 | 否定詞被吃掉 |
| 現在／等一下 | 時機判斷錯誤 |
| 開始／停止 | 控制反轉 |

## 二、指令類別

括號內為對應的 action，`{}` 為參數。每個參數**至少 5 種不同值**要被念到。

### A. 路口導引（`crosswalk_guide`／`traffic_light_query`）

```
現在是紅燈還是綠燈
現在可以過嗎
我對準斑馬線了嗎
我有沒有走歪
還要等多久
對面是綠燈嗎
```

### B. 尋物（`find_object`）

```
幫我找{顏色}的{物品}
我的{物品}在哪裡
附近有{物品}嗎
{位置}有什麼東西
前面有沒有{物品}
```

- 顏色：黑色、白色、紅色、藍色、灰色、透明
- 物品：保溫杯、鑰匙、背包、手機、錢包、眼鏡、雨傘、悠遊卡、耳機、外套
- 位置：桌上、椅子上、地上、口袋裡、包包裡

### C. 個人化物品登錄（`register_item`）

```
我要登錄一個新物品
這個叫做{我的錢包}
記住這個東西
刪掉{我的錢包}
```

### D. 文字識讀（`read_text`）

```
念這張{標示／站牌／門牌／招牌}
這上面寫什麼
這是幾號公車
這是{三百零七}號公車嗎
```

> 不收錄藥袋、藥單、處方等範例：劑量辨識錯一個字後果嚴重，改用站牌、門牌、包裝標示。

### E. 空間記憶（`anchor_memory`）

```
記住這個位置
我剛剛放在哪裡
帶我回到剛才的位置
```

### F. 系統控制（`system_control`）

```
停止　取消　再說一次　大聲一點　慢一點　重複　閉嘴
```

控制指令要**特別多錄**：使用者常在緊急或吵雜情況下講，而且講得短、急、大聲。「停止」每位錄音者至少 5 次，含在噪音中大聲喊的版本。

### G. 非指令（負例，`fallback`）

```
今天天氣真好　等一下再說　喂你在哪　嗯好
```

模型要學會「這句不是指令」。`sentence` 欄照實轉寫，意圖評估時標為 `fallback`。

## 三、錄音規格

### 3.1 說話者

| 角色 | 人數 | 說明 |
|---|---|---|
| 訓練集 | 8–10 人 | 性別、年齡、口音盡量分散 |
| **測試集** | 2–3 人 | **完全不出現在訓練集**，不含合成語音 |

說話者多樣性優先考慮性別、年齡、口音。主要使用者以長輩居多，長輩錄音的價值遠高於同齡者多錄。

### 3.2 錄音環境

| 條件 | 佔比 | 說明 |
|---|---|---|
| 安靜室內 | 40% | 基準 |
| **路口實景** | 40% | 車流、機車、行人號誌提示音 |
| 室內吵雜 | 20% | 人聲、冷氣、電視 |

人在吵雜環境會不自覺提高音量、放慢語速、加重咬字（Lombard 效應），這是事後混噪做不出來的特徵，所以路口實景要真的去路口錄。

### 3.3 技術規格

| 項目 | 規格 |
|---|---|
| 取樣率 | 16 kHz |
| 聲道 | 單聲道 |
| 格式 | WAV（PCM 16-bit） |
| 長度 | 每句 1–5 秒，前後留約 0.3 秒靜音 |
| 距離 | 手機離嘴 20–30 公分（模擬手持或掛在胸前） |

其他格式可用 ffmpeg 轉檔：

```bash
ffmpeg -i in.m4a -ar 16000 -ac 1 -c:a pcm_s16le out.wav
```

`recording/recorder.html` 錄音工具會直接輸出符合規格的檔案。

### 3.4 檔名

```
clips/{說話者代號}/{三位數流水號}.wav      例：clips/spk01/001.wav
```

說話者代號用 `spk01`、`spk02`，**不使用真名或學號**。

## 四、標註規格

| 項目 | 規則 | 範例 |
|---|---|---|
| 數字 | 一律國字 | 「十五號公車」不是「15號公車」 |
| 標點 | 短指令不加 | `現在是紅燈還是綠燈` |
| 空白 | 中文之間不留空白 | |
| 英文詞 | 保留原文 | `幫我找 iPhone` |
| 語助詞 | 照實寫 | 「嗯幫我找鑰匙」 |
| 口吃／重複 | 照實寫 | 「幫幫我找鑰匙」 |
| 聽不清 | 整句丟掉，不要猜 | |
| 用字統一 | 背包（不用揹包）、念（不用唸）、台（不用臺）、喂（語助詞，不用餵） | |

標註不統一會讓 CER 算出假錯誤。

## 五、檔案格式

```
sample_corpus/wayfinder_cmd/
├── train.tsv
├── test.tsv
├── validated.tsv
└── clips/
    ├── spk01/001.wav ...        真人訓練
    ├── spk09/001.wav ...        真人測試（不入 train）
    └── aug/...                  噪音擴增（只入 train）
```

`*.tsv` 以 Tab 分隔，兩個欄位，`path` 為相對於 `clips/` 的路徑：

```
path	sentence
spk01/001.wav	幫我找黑色的保溫杯
```

## 六、擴增

**測試集一律真人錄音。** 擴增只套用在訓練集。

### 噪音

| 項目 | 設定 |
|---|---|
| 來源 | 自錄路口環境音（車流、機車、行人號誌提示音、人聲） |
| SNR | 每句隨機 0–20 dB |
| 套用對象 | **只對訓練集**，測試集保持原樣 |
| 倍率 | 每句產生 1–2 個擴增版本 |

台灣路口的機車聲與行人號誌提示音很有代表性，建議到實際路口錄 5–10 分鐘。

---

## 七、送進訓練前的檢查清單

- [ ] 測試集說話者完全不出現在訓練集
- [ ] 測試集不含合成語音、不含噪音擴增
- [ ] 所有音檔為 16 kHz 單聲道 WAV
- [ ] TSV 以 Tab 分隔，欄位為 `path`、`sentence`，`path` 相對於 `clips/`
- [ ] 數字全部國字、無標點、中文間無空白、用字統一
- [ ] 六組最小對立組都有收錄，且跨噪音條件
- [ ] 「停止」等控制指令每人至少 5 次
- [ ] 含負例（不該觸發 action 的句子）
- [ ] 說話者代號不含真名或學號
- [ ] 每位錄音者都簽署語料公開同意書（去識別化釋出、可隨時撤回）；同意書不隨語料上傳
