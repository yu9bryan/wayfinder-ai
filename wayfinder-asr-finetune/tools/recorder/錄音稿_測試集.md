# 測試集錄音稿（40 句）

> 這份是**測試集**：錄音的人**不能**參與訓練集錄音，也不能用 TTS。
> 每人 40 句，約 10–15 分鐘。

## 錄之前

- 手機錄音 App 就可以，格式不拘（m4a 也行，我會轉成 16 kHz WAV）。
- 手機離嘴 **20–30 公分**，像手持或掛在胸前。
- **每句錄成一個檔**，檔名用編號：`001.m4a`、`002.m4a`……。如果一次錄完整段也可以，句子之間停 2 秒，我來切。
- 每句前後留一點空白，不用刻意字正腔圓，**用你平常跟手機講話的語氣**。
- 念錯就重念那一句，不要邊念邊改字。
- 錄音的人用代號 `spk09`、`spk10`，**不要用真名或學號**；錄之前請先簽語料公開同意書。
- 時間夠的話，在**路口**再錄一輪（車流、機車聲），檔名加 `_road`，例如 `001_road.m4a`。

## 句子

### 路口導引

| 編號 | 要念的話 |
|---|---|
| 001 | 現在是紅燈還是綠燈 |
| 002 | 現在可以過嗎 |
| 003 | 對面是綠燈嗎 |
| 004 | 我有沒有走歪 |
| 005 | 還要等多久 |
| 006 | 紅燈還要等多久 |
